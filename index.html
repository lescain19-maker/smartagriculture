Connect your ESP32

Run start.bat and open this dashboard from that server. Your ESP32 automatically discovers the server on the same LAN using the same device key.

The key stays in this tab’s memory. Use this HTTP server only on a trusted local network. Closing or reloading clears the key.

Local telemetry setup

1. Install Python 3.10 or newer. Set ESP32_DEVICE_KEY, then run python server.py --host 0.0.0.0.

2. Open firmware/ESP32_PCODE/ESP32_PCODE.ino. Set LOCAL_DEVICE_KEY in secrets.h; leave LOCAL_SERVER_URL empty. Keep all four code files together. The ESP32 discovers the server automatically.

3. Install LoRa by Sandeep Mistry, ArduinoJson 7, and WiFiManager by tzapu. Upload the gateway sketch and open Serial Monitor at 115200 baud. Keep your existing LoRa sensor node.

4. Open this dashboard at http://localhost:8000 and select Connect ESP32. Enter your local key.
